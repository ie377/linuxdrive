# linuxdrive.ru

Официальный сайт LinuxDrive — мультизагрузочная USB-флешка с 16 дистрибутивами Linux на базе Ventoy.

## Структура сайта

| Файл | Назначение |
| --- | --- |
| `index.html` | Главная: анимированный hero, преимущества, обзор 16 систем, видео, доставка, цена |
| `distros.html` | Каталог 16 дистрибутивов (сборка от 16.10.2026): сценарии выбора, сводная таблица, подробные карточки |
| `guide.html` | Руководство пользователя (веб-версия буклета издания 1.0) |
| `order.html` | Заказ: Яндекс Форма, бесплатная доставка до пункта выдачи Ozon, контакты |
| `politika.html` | Политика в отношении обработки персональных данных |
| `soglasie.html` | Согласие на обработку персональных данных |
| `assets/` | Общие стили (`css/style.css`) и скрипты (`js/main.js`) |
| `CNAME` | Домен для GitHub Pages |

## Видео

Положите вертикальный видеообзор **`linuxdrive.mp4`** в корень сайта (рядом с `index.html`).
До загрузки файла на его месте автоматически отображается аккуратная заглушка «Видеообзор скоро появится».
